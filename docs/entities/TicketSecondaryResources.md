# TicketSecondaryResources

Describes a secondary resource assigned to a Ticket. Secondary resources are different from the primary resource. A Ticket can have more than one Secondary Resource assigned, and can have secondary resources without a primary resource assigned.

- **Entity path:** `/atservicesrest/v1.0/TicketSecondaryResources`
