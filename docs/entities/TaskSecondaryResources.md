# TaskSecondaryResources

Describes a secondary resource assigned to a project Task. Secondary resources are different from the primary resource. A Task can have more than one Secondary Resource assigned, and a task can have secondary resources without a primary resource assigned.

- **Entity path:** `/atservicesrest/v1.0/TaskSecondaryResources`
- **Capabilities:** create ✓ · update — · query ✓ · delete ✓
