# QuoteLocations

Describes a location associated with an Autotask Quote. It defines address information for a Quote entity shipToLocationID and/or billToLocationID. Quotes are created and managed in Autotask through the CRM module.

- **Entity path:** `/atservicesrest/v1.0/QuoteLocations`
