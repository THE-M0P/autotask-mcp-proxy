## Ticket hygiene
- Ticket titles: `[Client] Short summary` (e.g. `[Acme] RDP not connecting`).
- Priority: P1 = client down, P2 = major degradation, P3 = standard,
  P4 = minor, P5 = request/quote. *(adjust to the team's actual scale)*
- Always set the company and primary contact before adding notes.

## Time entries
- Description format: `What was done — outcome` (one line, no client
  confidential data beyond what's on the ticket).
- Log time the same day where possible.
